**已知局限**

- 正例来自证据原句（词面重叠最高），所以精确率是**上限**；真实答案会改述，假阳性只会更多。
- 改述只有一张手工替换表，覆盖面远小于真实生成模型的表达方式。
- 样本量小且全部来自 2 页合成件，结论不能外推到真实文档；真实文档上应重跑同一探针。

## 2. 跨引擎一致性校验：标记的精确率 / 召回率

同一页文本作引擎 A；引擎 B 分两类：把每个不同高风险字段取值的**所有出现**一起改掉（已知错误），以及只改空行/标点/追加无字段文本/替换非字段词（对照）。报警判据即 diff_claims 的集合差非空。

| 指标 | 值 |
|---|---|
| 样本量 | 43 |
| TP / FP / FN / TN | 35 / 0 / 0 / 8 |
| 精确率（报警里真有字段错误的比例） | 100.0% （95% CI [90.1%, 100.0%]） |
| 召回率（注入错误被捕获的比例） | 100.0% （95% CI [90.1%, 100.0%]） |
| F1 | 1.000 |
| 报警样本平均冲突数 | 1.771 |

| 样本类型 | 真值 | n | 报警 | 检出 | 漏报 | 误报 |
|---|---|---:|---:|---:|---:|---:|
| `clean_blank_lines` | clean | 2 | 0 | 0 | 0 | 0 |
| `clean_confusable_char` | clean | 2 | 0 | 0 | 0 | 0 |
| `clean_extra_text` | clean | 2 | 0 | 0 | 0 | 0 |
| `clean_punctuation` | clean | 2 | 0 | 0 | 0 | 0 |
| `number` | injected | 35 | 35 | 35 | 0 | 0 |

本轮注入样本覆盖的字段类型：`number`；未覆盖：`docid`、`date`、`name`（该合成件里没有对应形态的字段，或形态不匹配检测器正则）。

**结论**：在该字段域内，标记可用于**送人工复核**：注入的字段错误全部被捕获，对照样本没有产生假警报。它的定位仍是『可疑，请复核』，不是『确认有错』。

**已知局限**

- 注入错误只落在检测器覆盖的字段类型（数值/文号/日期）内；字符级 OCR 错误（人名、术语错字）不报警——这是窄域设计，不是回归。
- 按『取值组』整体替换，模拟的是系统性读错；单点差异若把旧值改成一个页内已存在的值，集合差会完全看不见——这是当前实现的已知盲区，也意味着报警无法定位到具体出现位置。
- 合成件的字段分布与真实扫描件不同；本实验测的是比对机制，不是任何引擎的识别精度。
- 页面级报警不等于字段级定位准确；本探针未对单个冲突做人工真值标注。
