## 2. T3 契约修订（覆盖诊断报告 §3.1 的两处字面表述）

1. **句子边界集合**：`。！？!?`、`\n`、`\r`、U+2028（LINE SEPARATOR）、U+2029（PARAGRAPH SEPARATOR）、U+0085（NEL）、`\v`、`\f`。`；;，,：、` 仍是子句分隔符，不另起一句。
2. **借用源**：同一句内**最后一个带尾部引用标记的子句**（不再要求必须是最后一个子句）。借用后仍必须逐字可证。
3. **尾标记形态**：允许标记后跟 0–2 个闭合包裹字符（`）)】」』》”’"'`）与空白；ASCII `.` 不支持（见残余）。
4. **不变**：own-mark 优先；借用后走原 `_verbatim_match`；不跨句；`is_generic_negative`、`allow_zero_citations`、offender/detail 文案、strict、prompt、API/CLI/前端全部不变。

## 3. 验收测试（T3）

- Unicode 换行：`A， B [p.1]`、`\r`、` `、`\u0085`、`\v`、`\f` 均不得借用（B 报“没有引用标记”）；`\r\n` 仍不借用。
- 括号/引号：`A，B（[§1 ¶2]）。`、`A，B [§1 ¶2]）。`、`A，B [§1 ¶2]”` 通过（A、B 均逐字）。
- 中间引用：`A，B [§1 ¶2]，文档中未规定。` 通过（A、B 均逐字，最后为通用否定）。
- 非逐字仍失败：上述每类都保留一个“借用后非逐字”的反例，必须点名该子句失败。
- own-mark 优先、跨句不借用、多标记尾、连续分隔符、句号后引用、`_split_doc_clauses` 形状测试。
- 现有 179 个 hybrid 用例、全量 1015 passed / 4 skipped、ruff 全绿。
